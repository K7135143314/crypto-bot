# V0.8 First Atomic Fork Proof

Status: **SIMULATION-PROVEN for one controlled route/revert case**

GitHub Actions run: **75**

Pinned Base block: **52216060**

Route:

`Aave USDC flash loan -> Aerodrome Classic USDC/WETH -> Uniswap V3 WETH/USDC -> repayment/profit assertion`

## Controlled input

- Borrowed amount: 100 USDC
- Aave flash-loan premium: 5 bps
- Uniswap V3 fee tier: 100
- Minimum required profit: 1 USDC
- Real Base contract state was forked at the pinned block.
- No live wallet, private key, seed phrase, public transaction broadcast, or real funds were used.

## Measured fork result

- WETH after Aerodrome leg: `37003306581166387` wei WETH
  - approximately 0.037003306581166387 WETH
- USDC after Uniswap leg: `99878456` raw USDC
  - 99.878456 USDC
- Flash repayment required: `100050000` raw USDC
  - 100.050000 USDC
- Minimum profit requirement: `1000000` raw USDC
  - 1.000000 USDC
- Fork transaction gas used: **456,987**
- Transaction status: **0 / reverted**
- Outcome: **CORRECT_REVERT_PROFIT_FLOOR**

## What this proves

This was not a mocked calculation.

The fork call reached the explicit post-swap profit assertion only after:

1. Aave supplied the flash-loaned USDC.
2. Aerodrome executed the first swap.
3. Uniswap V3 executed the second swap.
4. The simulator measured the resulting USDC.
5. The ending balance was insufficient for repayment plus the configured minimum profit.
6. The EVM reverted the complete atomic transaction.

A failed-profit trade therefore did not leave a partial executed state.

## What remains unproven

- A profitable fork transaction that completes repayment successfully.
- The opposite route: Uniswap V3 -> Aerodrome.
- Exact scanner-estimate versus fork-result comparison at the exact same source block.
- Exact Base L1 data fee for the serialized executor transaction.
- Production MEV/order-flow behavior.
- Any real-money execution.

No live trading capability has been enabled.
